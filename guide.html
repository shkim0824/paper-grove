Paper Grove · 나의 논문 서재

Paper Grove, 이렇게 쓰세요.

논문을 넣고, 분류하고, 표시하며 읽습니다.

내 서재 열기 →

1. 논문 추가

＋ arXiv 링크 → 링크 붙여넣기 → 서재에 추가

abs·pdf 링크 모두 됩니다. PDF·제목·저자·arXiv BibTeX가 자동 저장됩니다. 보통 1–2분 걸리며 창을 닫아도 계속 처리됩니다. 내 파일은 PDF 업로드를 사용하세요.

2. Scholar에서 인용 가져오기

Scholar ↗ → 인용 → BibTeX → 복사
서재의 편집 → BibTeX에 붙여넣기 → 저장

BibTeX를 붙여넣어도 위의 제목·저자·출판처·연도 입력칸은 자동으로 바뀌지 않습니다. 필요하면 함께 수정하세요.

‘arXiv 인용 · 확인 전’은 arXiv에서 자동으로 가져온 인용이라는 뜻입니다.
논문이 맞는지, BibTeX와 출판 정보가 맞는지 확인했다면 편집 창의 ‘BibTeX와 출판 정보를 직접 확인했어요’를 체크하고 저장하세요.
‘인용 확인됨 · 직접 확인’으로 바뀝니다. 사용자의 확인 표시이며 자동 검증은 아닙니다.

정식 출판본을 찾지 못했다면 arXiv 인용을 그대로 사용하면 됩니다. 인용 내용을 수정하면 확인 체크가 풀립니다.

3. 폴더로 분류

논문 편집 → 분류 검색 또는 경로 입력 → Enter → 저장

  • Agent/Orchestration 입력 → Agent → Orchestration 폴더가 생깁니다. Agent/Orchestration/Conductor처럼 더 깊게 나눌 수 있습니다.
  • 한 논문에 여러 경로를 추가할 수 있습니다. 옆의 ×는 그 논문의 분류만 해제합니다.
  • 기존 분류는 검색해서 선택하세요. 대소문자만 다른 이름은 기존 표기를 재사용합니다. 의미가 다른 이름을 자동으로 합치지는 않습니다.
  • 왼쪽 Agent 클릭 → 모든 하위 논문. Orchestration 클릭 → 해당 하위 분류의 논문.
  • 화살표는 하위 폴더를 접고 펼칩니다. 전체 논문을 누르면 필터가 풀립니다.

기존 키워드와 arXiv 태그도 같은 분류 영역에 표시됩니다. 태그와 폴더를 따로 관리할 필요가 없습니다. 폴더는 논문에 붙이는 분류이므로, 어떤 논문에서도 사용하지 않는 경로는 목록에서 사라집니다.

4. 읽고 저장하기

논문 제목 클릭 → 상단 색 선택 → 문장 드래그

선택한 색은 바꾸기 전까지 계속 유지됩니다. 선택만을 누르면 색칠 없이 텍스트를 선택하고, 되돌리기 (Ctrl+Z / Command+Z)로 이번에 만든 표시를 최신순으로 취소할 수 있습니다. 다시 실행 (Ctrl+Shift+Z / Command+Shift+Z)으로 취소한 표시를 복원합니다. 새 표시를 만들거나 메모·색상을 수정하면 다시 실행 기록은 초기화됩니다. 메모는 오른쪽 목록에서 문장을 클릭해 필요할 때 작성하거나 수정하세요. 선택한 표시의 색 변경과 삭제도 오른쪽에서 할 수 있습니다.

약 1.2초 후 자동 저장됩니다. 메모 입력 후 Enter를 누르면 기기에 먼저 보관하고 편집창을 닫습니다. GitHub 저장은 뒤에서 계속 진행되며 상단에서 상태를 확인할 수 있습니다. 줄바꿈은 Shift+Enter를 사용하세요. GitHub 저장됨을 확인하고 다른 노트북으로 이동하세요. 원본 다운로드에는 하이라이트가 합쳐지지 않으며, 스캔본은 OCR 텍스트가 있어야 선택할 수 있습니다.

두 노트북에서 쓰기

두 노트북 모두 같은 사이트를 여세요. 각 브라우저에서 최초 한 번 토큰을 입력합니다. 저장한 논문·분류·메모는 창으로 돌아올 때와 30초마다 확인합니다. 같은 논문의 동시 편집은 마지막 저장이 우선합니다.

기능 업데이트는 브라우저 새로고침으로 받습니다. 파일을 다시 공유할 필요가 없습니다.
