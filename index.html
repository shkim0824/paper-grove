arXiv에서 추가

링크 하나로 PDF, 제목, 저자, arXiv BibTeX를 서재에 저장합니다.

abs · pdf 링크와 arXiv ID를 지원합니다. 버전 번호(v1 등)도 사용할 수 있습니다.

자동 인용은 arXiv 프리프린트 기준입니다. 정식 출판 정보는 추가 후 Scholar에서 확인할 수 있습니다.
가져오기는 창을 닫아도 계속되며, 같은 논문을 다시 넣으면 기존 자료를 유지합니다.

논문 정보 편집

인용에 필요한 정보와 읽으면서 떠오른 생각을 정리하세요.

/ 로 하위 분류를 만듭니다. 검색 결과를 선택하거나 Enter로 추가하세요.

Scholar → 인용 → BibTeX 복사 → 여기에 붙여넣기. 출판처·연도는 위 입력칸에서도 맞춰주세요.

체크 후 저장하면 ‘인용 확인됨 · 직접 확인’으로 표시됩니다. 자동 검증은 아닙니다.

저장소 설정

GitHub의 비공개 저장소를 연결하면 여러 기기에서 같은 논문과 메모를 볼 수 있습니다.

데이터용 private 저장소와 해당 저장소의 Contents: Read and write · Actions: Read and write 권한이 있는 fine-grained PAT를 준비하세요. 기본 브랜치를 사용합니다.

기억한 토큰은 localStorage에 저장됩니다. 개인 기기와 신뢰할 수 있는 앱 주소에서 사용하세요. 체크를 해제하면 탭을 닫을 때 토큰이 사라집니다.

로컬 모드

PDF와 메모를 이 브라우저의 IndexedDB에 저장합니다. GitHub 서재와 로컬 서재는 별개이며, 연결을 바꿔도 기존 자료는 유지됩니다.

자세한 설정·백업 방법은 함께 제공된 README.md를 참고하세요.
